# Changelog

Все заметные изменения Cursor Checker документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.0.2] - 2026-07-28

### Исправлено
- Исправлен расчёт умного дневного порога: теперь учитывается остаток квоты на начало дня, а не текущий — порог больше не уменьшается по мере траты лимита и не скачет утром
- Исправлен предпросмотр умного дневного порога в настройках — отображается то же значение, что используется для уведомлений

## [1.0.1] - 2026-07-25

### Исправлено
- Исправлено отображение лицензии в приложении

## [1.0.0] - 2026-07-25

### Добавлено
- Первый публичный релиз Cursor Checker для macOS
- Мониторинг квоты Cursor из строки меню: цикл %, траты за день, остаток, auto/API, дата окончания цикла
- Ручное подключение к Cursor через локальный session token
- Уведомления macOS и опциональные алерты в Telegram
- Окно настроек: подключение, пороги, интервал опроса, журнал, changelog, обновления
- Автообновление из GitHub Releases
- CLI-режимы `--once` и `--test`
